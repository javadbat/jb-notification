<Title>Styling</Title>

`JBNotification` exposes variables for toast sizing, state colors, borders, and text scale. Use official parts for the visible surfaces, and use `:state()` selectors when a recipe needs to target the current notification type.

## Common Design Tokens

Use the core theme docs as the source of truth for shared design-system variables:

- [Theme Colors](../../jb-core/theme/stories/colors.mdx) explains the general color palette variables, default colors, customization approaches, and color generation helpers.
- [Theme Sizes](../../jb-core/theme/stories/sizes.mdx) explains shared size and radius variables.
- [Theme Custom Galleries](https://javadbat.github.io/design-system/?path=/docs/theme-custom-material--docs) gathers the shared custom style recipes across components.

Notification recipes should use those common tokens where possible, then map them into `--jb-notification-*` variables where the toast needs a component-specific value.

## Styling Model

Use four layers when styling notification examples:

- Common design tokens are documented in [Theme Colors](../../jb-core/theme/stories/colors.mdx) and [Theme Sizes](../../jb-core/theme/stories/sizes.mdx).
- Reusable example theme packs live in [`docs/styles`](https://github.com/javadbat/design-system/tree/main/docs/styles) and can be shared across components.
- Component recipe files live in [`modules/jb-notification/stories/styles`](https://github.com/javadbat/design-system/tree/main/modules/jb-notification/stories/styles).
- Wrapper placement is owned by `jb-notification-wrapper`; notification recipes should focus on the toast item itself.

Each example uses one shared example theme pack from [`docs/styles`](https://github.com/javadbat/design-system/tree/main/docs/styles) and one notification-specific recipe from [`modules/jb-notification/stories/styles`](https://github.com/javadbat/design-system/tree/main/modules/jb-notification/stories/styles). The style story applies the theme class to the demo shell and the notification class directly to each `jb-notification`.

## Recommended Customization Path

1. Use `--jb-notification-*` variables first for width, padding, radius, icon size, state colors, border, and shadow.
2. Use `jb-notification::part(content)` for the visible toast surface when variables are not enough.
3. Use `jb-notification::part(icon)`, `::part(icon-svg)`, `::part(texts)`, `::part(title)`, and `::part(description)` for focused surface styling.
4. Use `jb-notification:state(success)`, `:state(info)`, `:state(warning)`, and `:state(error)` when a state-specific visual cannot be expressed by the state color variables alone.
5. Keep wrapper layout in `jb-notification-wrapper` variables so the item recipe can be reused in different stack positions.
6. Use common theme variables from [Theme Colors](../../jb-core/theme/stories/colors.mdx) and [Theme Sizes](../../jb-core/theme/stories/sizes.mdx) when the style should align with the design system.
7. Put reusable theme-pack values in [`docs/styles`](https://github.com/javadbat/design-system/tree/main/docs/styles) only when they should be shared by multiple component demos.

## Starter Recipe

Use this minimal recipe when a product only needs brand alignment for notification items.

```css
jb-notification.brand-notification {
  --jb-notification-width: 100%;
  --jb-notification-max-width: 24rem;
  --jb-notification-padding: 0.75rem 1rem;
  --jb-notification-border-radius: 0.75rem;
  --jb-notification-bg-color-success: #ecfdf5;
  --jb-notification-bg-color-info: #eff6ff;
  --jb-notification-bg-color-warning: #fffbeb;
  --jb-notification-bg-color-error: #fef2f2;
  --jb-notification-text-color-success: #047857;
  --jb-notification-text-color-info: #1d4ed8;
  --jb-notification-text-color-warning: #92400e;
  --jb-notification-text-color-error: #b91c1c;
  --jb-notification-border-width: 1px;
  --jb-notification-border-color: #dbe3ef;
  --jb-notification-box-shadow: 0 0.75rem 1.75rem rgb(15 23 42 / 0.14);
}

jb-notification.brand-notification::part(content) {
  border-inline-start-width: 0.25rem;
}
```

## Theme File Pattern

Use [Theme Colors](../../jb-core/theme/stories/colors.mdx) and [Theme Sizes](../../jb-core/theme/stories/sizes.mdx) as the common design-token guides. Theme-pack files should keep reusable demo variables in [`docs/styles`](https://github.com/javadbat/design-system/tree/main/docs/styles), then each component should keep its own style CSS in its story [`styles`](https://github.com/javadbat/design-system/tree/main/modules/jb-notification/stories/styles) folder.

```css
/* https://github.com/javadbat/design-system/blob/main/docs/styles/carbon.css */
.theme-name-style {
  /* shared design-system variables */
}

/* https://github.com/javadbat/design-system/blob/main/modules/jb-notification/stories/styles/style-carbon.css */
jb-notification.theme-name-notification {
  /* notification host variables */
}

jb-notification.theme-name-notification::part(content) {
  /* official notification surface */
}
```

This keeps common theme tokens reusable while making the official `JBNotification` styling API visible in one page.
